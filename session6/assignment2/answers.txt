=== التجربة 1: Specificity ===

توقعي:
توقعت يكون لون العنوان navy، لأن قاعدة h1 مكتوبة بعد القاعدتين الثانيين، فكرت إنه بياخد آخر وحدة.

النتيجة:
لون العنوان h1 بنفسجي (purple)، والقاعدة اللي حددت اللون هي #course-title.

السبب:
لما صححت course-title صارت الأولوية للـ id، فأخد اللون اللي موجود جواه.
قاعدة h1 خسرت رغم إنها مكتوبة بعد القاعدتين، لأن المتصفح بيشوف قوة الـ selector قبل الترتيب:
id أقوى من class، و class أقوى من اسم العنصر (h1).


=== التجربة 2: Source Order ===

توقعي:
بعد ما عطلت #course-title توقعت لما أحط البرتقالي آخر الملف يصير العنوان برتقالي،
ولما أنقله قبل الأخضر يرجع أخضر، لأن الثنتين class.

النتيجة 1 (.title { color: orange; } في آخر الملف):
العنوان صار برتقالي (orange).

النتيجة 2 (.title { color: orange; } قبل .title { color: green; }):
العنوان صار أخضر (green).

السبب:
لما حطيت .title { color: orange; } آخر إشي رح ياخد orange لأنه بنفذ آخر سطر.
ولما حطيتها قبل .title { color: green; } أخد آخر سطر.
يعني لما قاعدتين إلهم نفس القوة (class و class)، القاعدة الأخيرة في الملف هي اللي بتفوز.


=== التجربة 3: Inheritance ===

قبل (DevTools → Computed):
فقرة «Learn how the browser chooses a style.» لونها #374151
فقرة «Next class: Monday» لونها #374151
ولا فقرة إلها قاعدة CSS خاصة فيها، فالثنتين ورثوا اللون من الأب article.course-card.

توقعي:
توقعت إنه .course-card > p رح تلون الفقرة الأولى بس teal،
والفقرة الثانية تضل رمادي لأنها جوّا div.

القاعدة اللي كتبتها:
.course-card > p { color: teal; }

بعد:
فقرة «Learn how the browser chooses a style.» صارت teal
فقرة «Next class: Monday» ضلت #374151 (وارثة لون البطاقة)

السبب (ليش > وليس المسافة):
.course-card > p بتختار الـ p اللي هي ابن مباشر للبطاقة بس.
فقرة «Learn how» ابن مباشر للـ article، فتلونت teal.
فقرة «Next class» موجودة جوّا div.details، يعني مش ابن مباشر، فما تطابقت وضلت تورث لون البطاقة.
لو استخدمت المسافة .course-card p كان رح تتلون الفقرتين teal،
لأن المسافة بتختار أي p جوّا البطاقة بأي مستوى، وهذا عكس المطلوب.


=== اختبار الرابط ===

القواعد اللي كتبتها:
a:hover { color: crimson; }
a:focus-visible { outline: 3px solid orange; }

لما مرّرت الماوس:
لما حطيت الماوس فوق «View topics» صار لونه أحمر (crimson)،
ولما بعدت الماوس رجع للونه الأصلي.

لما استخدمت Tab:
لما بعدت الماوس وضغطت Tab لحد ما وصلت للرابط، ظهر إطار برتقالي حواليه (outline)،
وهيك بعرف وين أنا بالصفحة حتى لو ما بستخدم ماوس.
ولما كبست على الرابط بالماوس ما ظهر الإطار، لأن focus-visible بيشتغل مع الكيبورد بس.
