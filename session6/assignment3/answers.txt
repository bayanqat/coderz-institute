=== الخطأ 1: وحدة الـ h2 ===

اللي لاحظته قبل التصليح:
عنوان الـ h2 (CSS Foundations) كان كبير كثير، تقريبًا قد الـ h1،
وما كان باين الفرق بين العنوان الرئيسي والفرعي.

السطر اللي سبّب المشكلة:
.course-card h2 { font-size: 1.5em; }

تأثيره:
الـ em بتاخد الحجم من الأب، والأب هون هو البطاقة .course-card وحجمها 20px،
فصار الحساب 1.5 × 20 = 30px بدل 24px.

التصليح:
غيرت الوحدة لـ rem لأنها بتاخد الحجم من الجذر (html) اللي هو 16px:
.course-card h2 { font-size: 1.5rem; }
فصار الحساب 1.5 × 16 = 24px.

الاختبار والنتيجة:
  - قبل: font-size للـ h2 في Computed = 30px
  - بعد: font-size للـ h2 في Computed = 24px
  - في القراءتين: styles.css محمّل (بيبين في Styles)، html = 16px، البطاقة = 20px


=== الخطأ 2: --brand ===

اللي لاحظته قبل التصليح:
الـ h2 ما كان ماخد لون الـ brand، وكان لونه نفس لون النص العادي.
والـ h1 كان أحمر (tomato) بسبب الـ inline style.

السطر اللي سبّب المشكلة:
h1, h2 { color: var(--brnad); }

تأثيره:
اسم المتغير مكتوب غلط (brnad بدل brand)، فالمتصفح ما لقى متغير بهالاسم،
فما طبّق اللون، والعنوان ورث لون الـ body.

التصليح:
صححت الاسم: color: var(--brand);
وكمان شلت style="color: tomato" من الـ h1 في الـ HTML،
لأن الـ inline style أقوى من ملف الـ CSS الخارجي وكان مانع اللون يتطبق.

الاختبار والنتيجة:
  - غيرت --brand في :root إلى red، والـ h1 والـ h2 صاروا الثنتين أحمر مع بعض.
  - رجعت اللون الأصلي #12546c.


=== الخطأ 3: hover الرابط ===

اللي لاحظته قبل التصليح:
لما حطيت الماوس فوق رابط View schedule ما تغير لونه أبدًا.

السطر اللي سبّب المشكلة:
.action :hover { color: #6845a8; }

تأثيره:
المسافة بين .action و :hover معناها "أي عنصر جوّا .action لما يكون عليه hover"،
والرابط ما جواه ولا عنصر، فالقاعدة ما طبقت على الرابط نفسه.

التصليح:
شلت المسافة: .action:hover { color: #6845a8; }
هيك صارت تعني "الرابط .action نفسه لما يكون عليه hover".

الاختبار والنتيجة:
  - حطيت الماوس فوق View schedule، صار لونه بنفسجي (#6845a8)،
    ولما بعدت الماوس رجع للونه الأصلي.
  - بعدين بعدت الماوس وضغطت Tab لحد ما وصلت للرابط، ظهر حواليه إطار برتقالي 3px.
